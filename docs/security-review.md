# 安全与公开前检查

## 已做的脱敏

- 讯飞 3 个凭据移入本地 `project_config.h` 配置宏；不再在 `src/` 中出现历史值。
- 角色 A/B 的 MQTT 用户名、密码和主题名称移入本地配置；MQTT broker 和端口亦移入本地配置。
- 固定留言 API 地址移入本地配置，避免在公开源码暴露旧服务 IP。
- 删除开发者介绍中可能暴露邮箱的原 README 段落，重新编写为中性历史项目说明。
- 清理 IDE 自动生成的文件头假署名和不适用的企业版权模板；不删除真正第三方作者声明。
- 不包含原始 `lib/`、旧版密钥文件、`platformio.ini` 中的凭据或编译产物。

## 仍需本人执行

1. **立即重置/吊销**讯飞 APPID 对应密钥、MQTT Broker 账号密码。如果原 ZIP 曾流出，必须按已经泄露处理。修改本地代码并不能使旧密钥失效。
2. 检查原有 HTTP 留言服务和 MQTT broker 的访问权限；原源码使用明文 HTTP 留言服务，至少换到 HTTPS 并加入适当身份鉴别。
3. 确保无原始 ZIP、Git 历史、聊天附件、云盘共享或其他仓库存有旧凭据。
4. 检查 `docs/`、发布说明与截图里是否还有第三方个人信息或无权公开的技术资料。
5. 在团队同意的前提下公开；个人贡献必须另行写清，不可将协作代码说成自己独立完成。

## 审计边界

本轮只对 ZIP 中保留的首方代码做静态检查；不能证明其没有其他隐藏业务漏洞，也没有完成编译、依赖安全审计和真机测试。
